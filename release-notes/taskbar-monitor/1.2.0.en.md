- **Compact vertical widget on the right screen edge**: the widget is now a slim column docked to the right edge by default, so it no longer covers input boxes above the taskbar. Untick "Vertical Layout" in Settings to get the horizontal bar back.
- **Short labels, aligned numbers**: the vertical layout uses C / R / G / VR / D labels and shows percentages only; full figures stay in the detail card. Values have a fixed width, so the widget no longer jumps as numbers change.
- The widget stays pinned to the right edge when its width changes instead of overflowing off-screen.
